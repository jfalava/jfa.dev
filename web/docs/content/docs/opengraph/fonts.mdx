## Built-in fonts

The editor includes three families out of the box:

- **Pretendard** — a clean sans-serif for body and headlines.
- **Zilla Slab** — a sturdy slab serif.
- **Google Sans Code** — a monospaced option for code or labels.

Pick any of them from **Properties → Font family** when a text layer is selected.

## Custom fonts

Add your own fonts from **Properties → Upload font**:

- Supported formats: **WOFF2, WOFF, TTF, OTF**.
- Drag and drop or click to browse — the font is added to the family picker immediately.
- Custom fonts are saved with the project and included when you export a `.ogproj` archive.

WOFF2 variable fonts are recommended — one file covers many weights, so you can use Regular through Extra Bold without extra downloads.

All fonts stay in the browser. Nothing is uploaded.
