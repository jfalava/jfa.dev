OpenGraph (`@jfa.dev/opengraph`) is a local-first editor for OpenGraph images. No uploads, no buckets, no server-side transforms, no account. Everything runs in the browser.

## What you can do

- Create text, shape, and image layers
- Move, resize, rotate, and change opacity
- Reorder, hide, lock, duplicate, and delete layers
- Pick colors and type with built-in or custom fonts
- Work across multiple canvases in tabs
- Export to PNG or a portable `.ogproj` archive

Open the editor at `http://localhost:3101/opengraph/`.
