---
title: OpenGraph
description: Zero-cost, local-first OpenGraph image editor.
---

OpenGraph (`@jfa.dev/opengraph`) is a zero-cost, local-first
OpenGraph image editor. It provides a Photoshop-style layer workspace with no
uploads, no buckets, no server-side image transformations, and no account.

Everything lives in the browser:

- text, geometry, and local image layers
- layer selection, visibility, locking, reordering, deletion, undo/redo
- position, size, rotation, opacity, color, typography, and image-fit controls
- browser-only persistence via IndexedDB
- client-side PNG rendering at 1200 × 630 pixels

Run it locally at `http://localhost:3101/opengraph/`.
