The toolbox is a narrow column on the left, like Photoshop. The bottom shows your foreground and background swatches — click either to pick a new color.

## Move and Hand

- **V · Move** — select and drag layers. The blue outline shows the selection.
- **H · Hand** — pan the canvas. You can also hold **Space** to pan temporarily. Release **Space** to return to the previous tool.

## Insert

- **T · Text** — adds a new text layer in the center.
- **U · Shape** — adds a rectangle. Change it to an ellipse in **Properties → Shape**.
- **P · Image** — opens the file picker for PNG, JPEG, WebP, GIF, AVIF, and SVG. You can also drag images directly onto the canvas.

## Color

- **I · Eyedropper** — pick a color from any layer.
- **G · Fill** — the foreground and background swatches. Click a swatch to open the color picker.

All color controls use the same picker — drag the field or type a hex value.

## Edit & History

Below the swatches: **Duplicate** and **Delete** for the selected layer, then **Undo** and **Redo**.
