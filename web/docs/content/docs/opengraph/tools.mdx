The toolbox is a narrow column on the left, like Photoshop. The bottom shows your foreground and background swatches — click either to pick a new color.

## Move and Hand

- <Kbd variant="keycap">V</Kbd> Move — select and drag layers. The blue outline shows the selection.
- <Kbd variant="keycap">H</Kbd> Hand — pan the canvas. You can also hold
  <Kbd variant="keycap">Space</Kbd> to pan temporarily. Release
  <Kbd variant="keycap">Space</Kbd> to return to the previous tool.

## Insert

- <Kbd variant="keycap">T</Kbd> Text — adds a new text layer in the center.
- <Kbd variant="keycap">U</Kbd> Shape — adds a rectangle. Change it to an ellipse in **Properties →
  Shape**.
- <Kbd variant="keycap">P</Kbd> Image — opens the file picker for PNG, JPEG, WebP, GIF, AVIF, and
  SVG. You can also drag images directly onto the canvas.

## Color

- <Kbd variant="keycap">I</Kbd> Eyedropper — pick a color from any layer.
- <Kbd variant="keycap">G</Kbd> Fill — the foreground and background swatches. Click a swatch to
  open the color picker.

All color controls use the same picker — drag the field or type a hex value.

## Edit & History

Below the swatches: <Kbd variant="keycap">Duplicate</Kbd> and <Kbd variant="keycap">Delete</Kbd> for the selected layer, then <Kbd variant="keycap">Undo</Kbd> and <Kbd variant="keycap">Redo</Kbd>.
