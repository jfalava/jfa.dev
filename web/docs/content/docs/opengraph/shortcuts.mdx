## How to open the guide

- Press <Kbd variant="keycap">?</Kbd> (<KbdGroup><Kbd variant="keycap">Shift</Kbd><Kbd variant="keycap">/</Kbd></KbdGroup>) to open. Press <Kbd variant="keycap">Escape</Kbd> to close.
- Hold <Kbd variant="keycap">?</Kbd> for 400ms to peek — release to dismiss.

## Tools — single keys

No modifier needed. These work only when you are not typing.

- <Kbd variant="keycap">V</Kbd> Move / Select
- <Kbd variant="keycap">H</Kbd> Hand — or hold <Kbd variant="keycap">Space</Kbd> to pan
- <Kbd variant="keycap">T</Kbd> Text
- <Kbd variant="keycap">U</Kbd> Shape
- <Kbd variant="keycap">P</Kbd> Image
- <Kbd variant="keycap">I</Kbd> Eyedropper
