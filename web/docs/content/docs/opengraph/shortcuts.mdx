## How to open the guide

- Press **?** (`Shift+/`) to open. Press **Escape** to close.
- Hold **?** for 400ms to peek — release to dismiss.

## Tools — single keys

No modifier needed. These work only when you are not typing.

- **V** Move / Select
- **H** Hand — or hold **Space** to pan
- **T** Text
- **U** Shape
- **P** Image
- **I** Eyedropper

## Edit and File

- **Alt+N** New, **Alt+O** Import `.ogproj`, **Alt+S** Export ZIP, **Alt+Shift+S** Export PNG
- **Alt+R** Refresh layer
- **,** Toggle visibility of the selected layer
- **Undo** `Mod+Z`, **Redo** `Mod+Shift+Z`, **Duplicate** `Mod+J`

## View

- **Mod+Plus / Mod+Minus** Zoom in and out
- **Mod+0** Reset to 100%
