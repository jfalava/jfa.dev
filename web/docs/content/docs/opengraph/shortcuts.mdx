## How to open the guide

- Press <Kbd>?</Kbd> (<KbdGroup><Kbd>Shift</Kbd><Kbd>/</Kbd></KbdGroup>) to open. Press <Kbd>Escape</Kbd> to close.
- Hold <Kbd>?</Kbd> for 400ms to peek — release to dismiss.

## Tools — single keys

No modifier needed. These work only when you are not typing.

- <Kbd>V</Kbd> Move / Select
- <Kbd>H</Kbd> Hand — or hold <Kbd>Space</Kbd> to pan
- <Kbd>T</Kbd> Text
- <Kbd>U</Kbd> Shape
- <Kbd>P</Kbd> Image
- <Kbd>I</Kbd> Eyedropper

## Edit and File

- <KbdGroup><Kbd>Alt</Kbd><Kbd>N</Kbd></KbdGroup> New, <KbdGroup><Kbd>Alt</Kbd><Kbd>O</Kbd></KbdGroup> Import `.ogproj`, <KbdGroup><Kbd>Alt</Kbd><Kbd>S</Kbd></KbdGroup> Export ZIP, <KbdGroup><Kbd>Alt</Kbd><Kbd>Shift</Kbd><Kbd>S</Kbd></KbdGroup> Export PNG
- <KbdGroup><Kbd>Alt</Kbd><Kbd>R</Kbd></KbdGroup> Refresh layer
- <Kbd>,</Kbd> Toggle visibility of the selected layer
- Undo <KbdGroup><Kbd>Mod</Kbd><Kbd>Z</Kbd></KbdGroup>, Redo <KbdGroup><Kbd>Mod</Kbd><Kbd>Shift</Kbd><Kbd>Z</Kbd></KbdGroup>, Duplicate <KbdGroup><Kbd>Mod</Kbd><Kbd>J</Kbd></KbdGroup>

## View

- <KbdGroup><Kbd>Mod</Kbd><Kbd>+</Kbd></KbdGroup> / <KbdGroup><Kbd>Mod</Kbd><Kbd>-</Kbd></KbdGroup> Zoom in and out
- <KbdGroup><Kbd>Mod</Kbd><Kbd>0</Kbd></KbdGroup> Reset to 100%
