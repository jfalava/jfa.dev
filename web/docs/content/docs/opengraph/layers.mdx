## The stack

Layers are drawn bottom to top. **Background** is always at the bottom and locked. Drag a row onto another row to move it. Use the search field at the top to filter by name.

## The header

- **+** — open the create menu: **New text layer**, **New shape layer**, **New image layer**.
- **⋯** — open the manage menu: show or hide all, lock or unlock all, sort A→Z, reverse order, delete hidden, delete all.

## The row

Each row shows the icon, name, kind (**Text**, **Shape**, **Image**), and two toggles:

- **Eye** — hide or show. Hidden layers stay in the file but do not appear on the canvas or in exports.
- **Lock** — prevent selection, dragging, and deletion. Background is always locked.

Right-click a row for **Rename**, **Duplicate**, **Refresh** (reset position), and **Delete**. Double-click the name to rename inline.

## The footer

The bar under the list shows the layer count on the left and the canvas size on the right.

## Right-click menu

Right-click any layer to open the context menu with **Rename**, **Duplicate**, **Refresh**, and **Delete**.
