## List identifiers

Every list gets a UUID7 identifier generated server-side. Because UUID7 ids are
time-sortable and unique, the id itself is enough to address a list — the
routes are:

- `/keweke/` — empty shell / start screen
- `/keweke/:listId` — a loaded list

Sharing a list is just copying its URL.

## Data layer

List persistence is backed by a Durable Object data layer wired through
Alchemy; the server function that loads a shared list lives in
`server/lists.ts`.
