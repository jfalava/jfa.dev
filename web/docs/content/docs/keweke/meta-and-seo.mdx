## Dynamic list metadata

The list route sets a dynamic document title of `{title} - KEWEKE` and emits
OpenGraph and Twitter meta from the route loader via `getListShareMeta`.

- The description is `N items · M done` (or empty-list copy).
- Missing lists fall back to the root `keweke` title.
- `og:url` and `og:image` are intentionally omitted.

The server function backing this lives in `server/lists.ts`;
`lib/share-meta.ts` holds the shared helpers.
