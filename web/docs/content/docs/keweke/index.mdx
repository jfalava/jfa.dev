Keweke (`@jfa.dev/keweke`) is a small, shareable shopping-list app for
friends. Lists use UUID7 identifiers so a list can be shared directly as a
URL — no accounts, no lookup step.

- `/keweke/` — the empty shell
- `/keweke/:listId` — a loaded list

The UI is built on TanStack Start with Durable Object persistence behind the
`/keweke` router mount.
