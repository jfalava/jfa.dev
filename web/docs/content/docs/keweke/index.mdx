KEWEKE is a small, shareable shopping-list app for friends. No accounts, no lookup step — a list's link is its address.

- **Your lists** at `/keweke/` — the catalog stored on this browser
- **A single list** at `/keweke/:listId` — open it, edit it, copy the link to share

When you decide to share, the list becomes available on any device and stays in sync. How that works is explained in [Architecture](/docs/keweke/architecture).
