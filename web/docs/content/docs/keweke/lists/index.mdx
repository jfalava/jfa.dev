Every shopping list is its own page. The address of that page is the identifier you share.

- `/keweke/` — your catalog of lists on this browser
- `/keweke/:listId` — a single list

## Sharing

Copy the URL of a list to share it. There is no separate invite step — the link itself is the permission to view and, if you are signed in, to edit.
