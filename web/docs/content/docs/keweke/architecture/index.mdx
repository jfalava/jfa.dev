title: Architecture

KEWEKE is built as a local-first app that can become collaborative without you changing how you use it. Most work happens in your browser; the service only steps in to keep shared copies in sync.

## At a glance

- **Your browser is the source of truth** for personal lists. They live in IndexedDB and work offline.
- **Your identity is a key, not an email.** An Ed25519 keypair is created on first visit. The public key's fingerprint is your user and device identifier.
- **Shared lists live on the edge.** Each list is a Durable Object with its own SQLite database. It broadcasts changes over WebSockets.
- **No upload step for sharing** — a list's URL is its address. Copying the link shares it.
