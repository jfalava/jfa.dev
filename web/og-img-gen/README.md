# OG Image Generator

The `@jfa.dev/og-img-gen` app is the layer-based OpenGraph image editor scaffold for the monorepo. It currently contains the shared JFA header and a static Photoshop-style workspace; editor behavior will be added in a later pass.

Run it from the repository root:

```bash
bun run --filter @jfa.dev/og-img-gen dev
```

The app is available at `http://localhost:3101/`.
